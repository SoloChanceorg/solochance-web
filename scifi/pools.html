The first pool to gamify Bitcoin mining. It invented stratum gaming: the top 100 addresses ranked by share score each receive an equal cut of the block reward, turning solo mining from an all-or-nothing bet into a leaderboard you can actually climb with a small miner like a Bitaxe. [ JOIN ]

Established, trusted pools with a proven track record of found blocks — from strict solo to the newer Parasite scheme. For miners who want reliable, time-tested options with almost no risk.

Pool Description
CKPOOL.ORG
The Prometheus of solo Bitcoin mining, built by Con Kolivas — who also created cgminer. The ckpool and cgminer duo have shaped the foundation of Bitcoin mining as we know it. [ JOIN ]
PUBLICPOOL.IO
Open-source, zero-fee solo Bitcoin mining pool — find a block and keep 100% of the reward. Self-hostable for full sovereignty, or use the hosted version at web.public-pool.io. [ JOIN ]
ATLASPOOL.IO
A globally deployed solo Bitcoin mining pool with a 1.5% fee. Uses BGP Anycast across 9 worldwide endpoints to automatically route miners to the closest server for minimum latency. [ JOIN ]

Block finder earns 1 BTC outright — the rest is shared proportionally with all miners since the last block. Zero fees, Lightning Network payouts, and a 10-sat withdrawal minimum. Built for home miners under the motto "Plebs eat first." [ JOIN ]
